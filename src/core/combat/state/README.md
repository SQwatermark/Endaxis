# 战斗切面数据模块

本目录定义完整帧边界上可以保存、复制和恢复的战斗数据。运行时类、动作程序、回调、校验和推进逻辑
放在 `runtime` 等业务目录；这里不执行游戏规则。

五个文件按依赖方向排列：

1. `environmentState.ts`：时钟、资源、生命、时间膨胀、连携窗口、输入游标和全局编号；
2. `actionState.ts`：黑板、动作进度和动作宿主持有的句柄账本；
3. `abilityState.ts`：技能选择、单次技能执行、冷却、事件来源和干员初始化；
4. `instanceState.ts`：全局 Buff、能力实体、投射物、SkillAffix 和 Buff 动作宿主；
5. `combatState.ts`：把以上数据与干员、敌人和事件目录组成 `CombatStateGraph`。

运行模块应直接导入实际需要的文件。这里不提供汇总导出文件，以免隐藏依赖方向或引入运行时循环。
新增切面字段时，先按所有权放进以上层次；只有一组数据确实形成新的独立子系统时才新增文件。
