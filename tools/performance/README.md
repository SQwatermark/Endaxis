# 真实轴性能基线

仓库根目录执行（只读项目文件，报告写标准输出）：

```powershell
node --experimental-strip-types tools/performance/benchmark-real-timelines.ts path/to/project.json
```

输入是正式 EndaxisProject，可先通过 tools/legacy-timeline 转换旧存档。
每个方案完整重算四次：原落点、首技能向后移动 1/2/3 帧，记录缓存键、模拟、服务层投影和结果结构化克隆耗时。
保留项目自定义定义库，不搬运旧结果，不改游戏规则，不覆盖存档。空轴没有可移动技能，后续样本可能命中缓存。

## 真实轴保存点验证

```powershell
npm run verify:real-timeline-checkpoints -- path/to/project.json [方案序号] [随机种子]
```

方案序号从 0 开始，默认验证第一个方案；随机种子默认是 `123`。工具使用与页面相同的项目级数据仓库，
依次比较完整排程、逐帧提交和多个事件边界保存后分支续算的状态、回执与最终结果。任一路径不一致都会
直接失败。输出包含输入文件摘要、方案、模式、保存帧、回执摘要和期望伤害，可用于同一输入的跨提交对照。

这是 Node/Vite 模块环境的计算基线，不是浏览器 FPS：首次运行包含 JIT 等热身影响，
simulationMs 包含原有模拟入口中的编译与部分回执整理，不能误称纯战斗内核耗时。
浏览器还需单独测 Worker 冷启动、传输、Vue 更新、布局绘制和真实拖动的帧间隔。
结果含项目名称/ID，私人存档及报告留在 tmp，不提交。

2026-09-08 初测：本地三轴（23/11/68 个技能）移动落点全量重算约 199–428ms，
服务层投影约 0.3–11ms，结构化克隆约 4–21ms。只代表该机器与该次运行，非性能承诺。
后台化首先隔离主线程阻塞，不代表模拟计算量已经降低；仍需测结果传输和整轴渲染的剩余成本。
