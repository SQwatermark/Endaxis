# 效果与反应系统

## 概述

终末地的战斗系统围绕**元素附着 → 元素爆发 → 元素反应**和**物理异常**两条线展开。Endaxis 完整实现了这些机制。

## 元素系统

### 四元素

| 元素 | 英文 | 附着效果 | 异常状态 | 异常效果 |
|---|---|---|---|---|
| 灼热 | Heat | 灼热附着 | 燃烧（Combustion） | 持续灼热伤害 |
| 寒冷 | Cryo | 寒冷附着 | 冻结（Solidification） | 无法行动 + 寒冷伤害 |
| 电磁 | Electric | 电磁附着 | 导电（Electrification） | 法术脆弱（受到法术伤害增加） |
| 自然 | Nature | 自然附着 | 腐蚀（Corrosion） | 物理/法术脆弱 + 破防效果翻倍 |

### 附着与爆发

```
施加灼热伤害 → 灼热附着（1层）
再次施加灼热 → 灼热爆发（Burst，不增加层数）
```

附着最多 N 层（通常 3-4 层），爆发不改变层数但可以触发爆发效果。

### 元素反应

当目标同时拥有两个不同元素的附着时触发反应：

```
灼热 + 寒冷 → 无直接反应（互斥消耗）
灼热 + 电磁 → 无直接反应
灼热 + 自然 → 无直接反应
寒冷 + 电磁 → 冻结（Solidification）
寒冷 + 自然 → 腐蚀（Corrosion）
电磁 + 自然 → 导电（Electrification）
电磁 + 灼热 → 燃烧（Combustion）※
自然 + 灼热 → 腐蚀（Corrosion）※
```

## 物理异常系统

| 异常 | 英文 | 效果 |
|---|---|---|
| 破防（物理脆弱） | Vulnerability | 受到的物理伤害增加 |
| 倒地 | Knock Down | 控制效果 |
| 击飞 | Lift | 控制效果 |
| 猛击 | Crush | 消耗破防层数造成额外伤害 |
| 碎甲 | Breach | 降低物理防御 |

物理异常通过**失衡**机制触发——累积失衡值 → 进入失衡节点 → 连续消耗节点至 0 → 触发破防。

## 效果生命周期

```
触发条件满足
    │
    ▼
效果创建（EFFECT_START）
    │
    ├── 堆叠策略：
    │   REFRESH_DURATION — 刷新持续时间
    │   INDEPENDENT     — 独立层数，各自计时
    │   REPLACE         — 替换同 ID 效果
    │
    ▼
效果持续（duration 秒）
    │  每帧 tick 计算属性修改
    │
    ├── 自然过期（EFFECT_END）
    │
    └── 提前消耗（consume by action condition）
        → 减少持续时间为消耗时刻
        → 标记 isConsumed = true
```

## 关键机制

### 先伤害后效果（Hit before Effect）

模拟严格遵循：**一次命中的伤害不会受益于该命中施加的效果，但会受益于该命中消耗的效果。**

这意味着：
- 战技的伤害不受战技自身施加的附着/脆弱影响
- 但战技消耗的现有附着/脆弱**会**增加战技伤害

这与游戏实际表现可能略有出入（详见 FAQ）。

### 终结技能量系统

1. 消耗技力 → 获得终结技能量（受充能效率加成）
2. 部分技能直接获取终结技能量
3. 终结技强化期间，该轨道的终结技能量获取被阻塞
4. 终结技能量可跨轨道分享（受 `acceptTeamUltEnergy` 控制）

### 暴击时触发

当前模拟的局限：所有"暴击时触发"效果按"命中时触发"处理，计算出的伤害可能略高于实际。
