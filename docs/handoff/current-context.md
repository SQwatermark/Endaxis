## 必须保持的边界

- 原生规则与同版本证据归 combat-spec；Endaxis 使用单敌人、无敌人主动行为、攻击命中的场景。
- SP 属于全队，终结技能量属于干员；不建立投射物私有能量账户。
- 回收顺序为结束当前技能 → reset 通知（来源仍可读）→ ClearSource。
- 切面先于新输入；技能、切人及人工标记都从输入边界提交，未来不能影响过去。
- 回执历史与瞬时状态分离，分支共享不可变前缀；固定程序与每次施放登记分离。
- 切面数据归 combat/state，模块依赖单向；实际对象图的必要循环与共享引用保留。
- 不手改生成技能文本，不重复实现公共结构，不提交中间产物、转储或本机环境。
