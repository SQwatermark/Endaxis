  图标审计涉及 44 个不同资源路径，均存在。独立浏览器验证页检查图标、节点、缩放、拖动和关闭；

Node CLI 执行验证，不删除或重装共享依赖。重型检查串行、限制 worker，见[验证指南](../development/validation.md)。

## 必须保持的边界

- 原生规则和同版本证据归 combat-spec；Endaxis 为单敌人、无敌人主动行为、攻击确保命中的场景。
- SP 属于全队，终结技能量属于干员；不建立投射物私有能量账户。
- 回收顺序：结束当前技能 → reset 通知（来源仍可读）→ ClearSource。
- 切面先于新输入；技能、切人和人工标记都从输入边界提交，未来不能影响过去。
- 回执历史与瞬时状态分离，分支共享不可变前缀；固定程序与每次施放登记分离。
- 切面数据归 combat/state，模块依赖单向；必要的真实对象循环与共享引用保留。
- 不手改生成技能文本，不重复实现公共结构，不提交中间产物、转储或本机环境文件。
