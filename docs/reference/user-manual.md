# 使用手册

## 快速开始

1. 访问 https://www.end-axis.com/
2. 页面默认有一个空方案（Project），包含 4 条空轨道
3. 点击轨道上的"选择干员"按钮，从列表中选择一名干员
4. 在左侧动作库中展开技能列表，将技能拖入对应轨道
5. 调整技能块位置（拖拽）和连线关系
6. 点击"分析"按钮查看伤害统计

## 界面指南

### 时间轴区域

- **标尺**：上方显示游戏时间，下方为现实时间（含时停偏移）
- **轨道**：4 条水平轨道对应 4 名干员
- **技能块**：彩色矩形块，从左侧拖入或轨道间拖拽
- **连携曲线**：彩色贝塞尔曲线连接相关技能
- **效果覆盖层**：技能块下方显示施加的效果图标

### 工具栏

| 按钮 | 快捷键 | 功能 |
|---|---|---|
| 框选 | Ctrl+B | 框选多个技能块进行批量操作 |
| 连线工具 | Alt+L | 启用连线模式，拖拽创建连携/消耗关系 |
| 辅助线 | Ctrl+G | 显示鼠标位置对齐辅助线 |
| 吸附精度 | Alt+S | 切换 0.1s 或 1 帧（1/60s）吸附 |
| 分析 | — | 运行模拟并显示伤害分析 |
| 导出 | — | 导出图片/JSON/数据码 |

### 技能块操作

| 操作 | 方法 |
|---|---|
| 拖入技能 | 从左侧技能库拖拽到目标轨道 |
| 移动技能 | 在轨道内水平拖拽 |
| 复制技能 | Alt+拖拽 |
| 删除技能 | 选中后按 Delete |
| 锁定位置 | 右键 → 锁定位置 |
| 禁用计算 | 右键 → 禁用（不参与模拟） |
| 改变颜色 | 右键 → 颜色 |
| 连线设置 | 右键 → 连线设置（设置出/入点） |
| 快速对齐 | 右键 → 左对齐/右对齐/接前方/接后方 |

### 左侧面板

- **属性标签**：调整干员等级（1/20/40/60/80/90）、潜能
- **武器标签**：选择武器、设置等级和精调
- **装备标签**：选择 4 件装备、设置精锻等级
- **技能库**：展开干员所有技能，点击选中或拖拽排轴

### 连携系统

1. 启用连线工具（Alt+L）
2. 点击一个技能块的出点（小圆点）
3. 拖拽到另一个技能块的入点
4. 效果消耗连线：右键 → 连线设置 → 从效果拖到消耗该效果的动作

### 循环分界线

右键时间轴空白处 → 添加循环分界线。用于标记技能循环的起止点，方便分析循环 DPS。

### 主控干员切换

右键时间轴 → 在此处切人。模拟时，不同时间段的"主控干员"会不同，影响部分效果的触发目标。

## 方案管理

| 操作 | 方法 |
|---|---|
| 新建方案 | 点击标签栏 + 按钮 |
| 复制方案 | 右键方案标签 → 复制 |
| 重命名 | 右键方案标签 → 重命名 |
| 删除方案 | 右键方案标签 → 删除 |
| 继承资源 | 右键方案标签 → 继承资源并生成新方案 |

## 导入导出

### 导出

| 格式 | 用途 |
|---|---|
| JSON 文件 | 完整项目保存，可重新导入 |
| PNG 图片 | 长图导出，同时嵌入数据码（可被其他 Endaxis 用户导入） |
| 数据码 | Base64+压缩文本，适合粘贴分享 |

### 导入

- 拖拽 .json 或 .png 文件到页面
- 或点击工具栏"加载"按钮选择文件
- 或粘贴数据码到"接收"对话框

## 伤害分析

运行分析后显示：

1. **总伤害 + 循环时间 + DPS**
2. **干员贡献饼图** — 各干员占总伤害的比例
3. **元素伤害分布** — 按物理/灼热/寒冷/电磁/自然分类
4. **LMDI 贡献分解** — 精确到每名干员的增益/伤害/反应贡献

### LMDI 分配模式

- **按叠层**：破防、导电、腐蚀的收益按叠层比例分配
- **按施加者**：所有收益归触发者

## 战斗日志

底部面板显示完整战斗事件序列，可按类型筛选：

- 伤害（Damage Hit）
- 附着/反应（Effect Start/End/Reaction）
- 技力（SP Change）
- 终结技充能（Ultimate Charge）
- 失衡（Stagger）
- 其他

## 移动端

移动端浏览器自动切换为只读视图：
- 查看排轴时间线
- 查看干员配装
- 查看技能信息
- 支持导入分享码

## 已知局限

1. **暴击时触发**：所有"暴击时触发"效果按"命中时触发"处理，伤害可能略高
2. **先伤害后效果**：模拟严格遵循"先伤害后效果"规则，与游戏实际可能有偏差
3. **伤害数值**：模拟统一向下取整，游戏内为四舍五入
4. **伤害上限**：部分敌人的伤害上限机制可能不完全准确
5. **仅供优化配队使用，请勿用来拉踩攻击他人**
