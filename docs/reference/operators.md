## 属性成长

干员属性随等级（1/20/40/60/80/90）成长：

| 属性 | 说明 |
|---|---|
| 基础攻击力 (Base ATK) | 影响伤害计算中的 ATK 基数 |
| 基础生命值 (Base HP) | 影响 HP 计算基数 |
| 力量 (Strength) | 影响物理伤害和 HP 加成（每点力量 +5 HP） |
| 敏捷 (Agility) | 影响暴击率和冷却缩减 |
| 智识 (Intellect) | 影响法术强度和技能效果 |
| 意志 (Will) | 影响生存能力和终结技效率 |

### 主属性与副属性

每个干员有一个主属性和一个副属性。主属性对攻击力的贡献系数为 0.005/点，副属性为 0.002/点：

```
ATK属性加成 = 1 + 0.005×主属性 + 0.002×副属性
```

（部分干员通过天赋/潜能增加额外属性的攻击力系数。）

## 技能系统

每名干员拥有以下技能槽位：

| 技能槽位 | 类型标识 | 说明 |
|---|---|---|
| 重击 | `basicAttack` | 普通攻击 |
| 闪避 | `dodge` | 闪避技能 |
| 下落攻击 | `dive` | 从高处发动的攻击 |
| 处决 | `finisher` | 对失衡敌人发动的特殊攻击 |
| 战技 | `battleSkill` | 主动技能（消耗技力） |
| 连携技 | `comboSkill` | 连携技能（有冷却时间，触发时停） |
| 终结技 | `ultimate` | 大招（消耗终结技能量，触发时停） |

每个技能定义包含：倍率（multiplier）、命中序列（hits）、技力消耗（spCost）、冷却时间（cooldown）、动作时长（duration）、连携触发窗口（triggerWindow）等。

## 天赋与潜能

- **天赋（Talent）**：2 组，每组多个等级（2-3 级），通过等级提升解锁
- **潜能（Potential）**：5 个等级，通过抽到重复干员解锁

天赋和潜能通过 `TriggerEffect` 系统定义。
