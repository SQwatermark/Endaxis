# 术语表

本文档统一项目中使用的专有名词中英文对照，数据来源为 `src/i18n/` 目录下的翻译文件。

## 游戏术语

### 基础概念

| 中文 | 英文 | 说明 |
|---|---|---|
| 干员 | Operator | 可操控的角色单位 |
| 排轴 | Timeline Arrangement | 按时间顺序编排技能释放 |
| 方案 | Scenario / Project | 一个完整的排轴配置 |
| 轨道 | Track | 时间轴上一条干员的技能序列 |
| 连携 | Combo / Link | 战斗中不同干员间的技能联动 |
| 连携技 | Combo Skill | 干员的连携技能 |
| 重击 | Final Strike / Basic Attack | 普通攻击 |
| 战技 | Battle Skill / Skill | 主动技能 |
| 终结技 | Ultimate | 需要积攒终结技能量释放的大招 |
| 下落攻击 | Dive Attack | 从高处发动的攻击 |
| 处决 | Finisher / Execution | 对失衡敌人发动的特殊攻击 |
| 闪避 | Dodge | 闪避技能 |
