# 被动 UI 重复回执压缩

本页验证只保留被动 UI 数值变化的效果，和[不改变完整输出的热路径优化](simulation-optimization-campaign.md)分开验收。比较基线为 `91bbf67e`，包含已保留的诊断索引、冷却和时间倍率优化；游戏规则与公开轴输入不变。

## 记录合同

`CharacterPassiveUiValueChanged` 在同一目标上连续发布相同原始数值、来源也相同时，不再追加第二条记录。其他事件插入不打断这个目标的连续数值状态，其他目标拥有独立状态。

- 首次零值、数值变化、归零和来源变化仍记录；A → B → A 的来源切换不能跨来源压缩
- 比较有限原始数字，使用 `Object.is` 区分正负零，不四舍五入或按显示上限钳位；非有限值保留原有导出报错行为
- 带额外数据、对象来源或运算证据的记录不压缩，并重置该目标的连续比较资格
- 只减少这类 UI 回执，不减少动作执行，不删除技力、伤害、状态、轨迹或诊断事实

收集器持有按目标索引的最后已发布数值和来源，不持有调用方的可变数据。历史追加成功之后才更新索引。保存点仍拥有完整不可变历史，恢复时一次扫描前缀重建索引；每个分支拥有自己的索引，没有跨战斗缓存或新增战斗状态字段。导入旧历史不压缩前缀，不重排已有序号。实时记录从新的连续序号继续。

因此导出的日志行数会减少，后续回执序号也会前移；本次不能声称完整输出哈希不变。序号属于当前历史分支，界面和诊断必须使用同一份历史里的引用。

## 语义验收

专用工具分别生产构建优化前和优化后源码；构建阶段拒绝混用两个源码目录。独立比较器从旧回执判定哪些记录可以删去，再检查每条保留记录的全部字段与顺序。只映射真正的回执身份、资源/生命/失衡曲线的回执序号以及诊断引用，不改连携窗口内部计数。

六轴完整可传输结果在这项明确映射后相等，完整战斗状态逐项相等。准备段到截止帧共 18,622 帧的 HUD 全部一致，被动 UI 曲线完全一致，Buff 曲线及其回执身份映射一致。伤害、资源、来源证据与全部诊断均包含在完整结果比较中。

## 性能测量

与原基线工具相同，六轴独立进程、无切面和结果缓存，每组首跑一次、热身三次、测量二十次。两轮交替版本顺序，第二轮反向遍历六轴。正式计时没有 CPU 或分配采样。完整原始结果只保存在本机，公开机器摘要不包含原始存档、路径或 profile。

不能宣称六轴普遍提速：稠密轴的完整服务基本处于波动范围，无删减的伊冯轴两轮反而慢 3.1–8.8%，其他对照也有正负变化。共享宿主有明显漂移；本次只支持电队在这两轮中的有限耗时下降和明确的日志、复制缩减。既不把无删减轴的下降归功于压缩，也不隐藏变慢的样本。冷首跑、p95、CPU 和全部逐次数据保存在[机器摘要](passive-ui-receipt-compression.json)；不能把单次冷跑或 20 次的第 19 个排序样本当作稳定尾延迟保证。

### 分配流量与恢复代价

正式计时结束后，电队与稠密轴分别复跑 CPU/分配采样及无采样 control，每种模式两个独立进程，五次热身、十二次采样模拟；反向排列第二轮模式。原始 profiles、源码映射和二进制结果不提交。采样开销没有混入上面的服务耗时对照。

| 轴       | 压缩前估算分配 MB/次，两进程 | 压缩后 MB/次，两进程 |
| -------- | ---------------------------: | -------------------: |
| 电队     |                258.7 / 259.5 |        255.9 / 256.6 |
| 稠密自然 |                340.2 / 341.7 |        342.4 / 340.2 |

电队采样估算分配流量下降约 1.1%，稠密轴没有一致改善。V8 分配采样包含采样期间已被回收的对象，既不是精确对象数量，也不是存活堆或峰值；不能把日志减少 32.8% 说成整体内存减少 32.8%。

恢复时新增一次前缀扫描：单独新建收集器的暖态微测量，六轴中位约 0.05–0.34 ms/次，电队约 0.22 ms、稠密约 0.34 ms；原收集器约 0.0003 ms。每个进程丢弃三批、测二十批，每批二十个独立收集器。该测量不包含图复制、程序绑定、投射物恢复或后续模拟，不能当作完整切面恢复时间。选择这个有界额外成本，避免引入第二份需要同步和保存的战斗状态；它不发生在逐帧执行中。

## 回归范围与已知限制

- 应用与离线工具类型检查通过；应用 460 个测试文件、3,860 个测试通过，既有 GC 条件测试跳过 1 个；生产构建通过
- 追加回归覆盖首次零、原始小数变化、正负零、来源交错、附加来源证据、无损导入前缀、兄弟与嵌套分支、真实会话保存/回退后的重复值及归零
- 五份公开轴的 expected / sampled（seed 123）共 74 个切面分支通过，完整排程、逐帧输入与分支续算一致
- 伊冯轴 `6aa952` 的额外恢复探针仍有既存 `missing projectile reset handler 0` 问题，优化前的 `483f437a` 已同样复现。本次没有扩大范围修复；该轴全量模拟、压缩前后完整结果与逐帧 HUD 比较通过，但不能声称其切面恢复通过
- 没有改变 UI 布局，本轮验证计算输出与投影，不提供浏览器 FPS、实际 Worker 往返或真实设备内存结论

保留这项修改的理由是明确且局部的：电队日志与复制显著缩减，完整游戏与展示语义通过专用验收；不把它描述成覆盖所有轴的内核提速。
