# 处决与下落攻击数据差异

## 结论

处决和下落攻击都应当是独立技能组，但技能等级取自普通攻击：

- `finisher`：独立技能组，`levelSource: 'basicAttack'`；
- `plungingAttack`：独立技能组，`levelSource: 'basicAttack'`；
- 两者都不属于普通攻击连段，也不应作为连段中的额外段落；
- 投射物命中、落地回调等内部技能不是技能库中的独立可拖动技能。

旧版 `createFinisherEntry` 和 `createDiveEntry` 为所有干员注入相同模板。模板只保留了
展示总倍率，无法表达真实命中拆分、时序、投射物和角色机制，应由逐干员数据取代。

## 数据来源

本次盘点使用本地 1.4.4 数据：

- `CharGrowthTable.json`：普通攻击技能组成员；
- `SkillPatchTable.json`：逐等级黑板数值；
- `SkillData/*.json`：时间轴动作、伤害单元、计算公式、标签和附加行为；
- 本地 `combat-spec`：`BreakingAttackCalculation`、伤害标签和动作执行语义。

`chr_0002_endminm`、`chr_0003_endminf` 是废弃管理员数据，不作为独立干员统计。
当前 `chr_9000_endmin` 仍引用这些旧技能 ID，而本地 SkillData 已将对应文件过滤，因此管理员
需要从其实际运行时形态映射单独恢复。阿黛拉的处决主 SkillData 当前也缺失，暂不能完整比较。

## 处决

### 共同结构

- 源技能通常命名为 `power_attack`，原生技能类型是 `BreakingAttack`；
- 伤害标签统一包含 `NormalAttack | PowerAttack`；
- 等级 1 到 12 的展示总倍率统一为
  `400/440/480/520/560/600/640/680/720/770/830/900%`；
- 基础伤害使用 `BreakingAttackCalculation`：攻击力、敌人处决承伤倍率、技能总倍率与
  命中拆分倍率共同参与计算；
- 只能在敌人处于失衡状态时释放；
- 技能等级跟随普通攻击等级。

因此，敌人的 `finisherMultiplier` 应当进入处决基础计算，不能在普通伤害完成后作为一个
只由 UI 动作类型决定的末端倍率补乘。

### 命中拆分差异

| 形态                     | 干员示例                                                     | 特征                                                 |
| ------------------------ | ------------------------------------------------------------ | ---------------------------------------------------- |
| 单次直接命中             | 佩丽卡、狼卫、赛希、余烬、雪绒、伊冯、萤石、终末仪式         | 主技能内一个主要伤害动作                             |
| 两段命中                 | 汤汤、陈千语、黎风、莱万汀、大潘、秋栗、管理员以外的部分近战 | 多个命中倍率之和构成总倍率                           |
| 三段命中                 | 弧光、艾维文娜、洛茜、边境、庄方宜                           | 前置小倍率命中加末段主要命中                         |
| 多段命中                 | 吉尔伯塔、诀、米芙                                           | 五段以上，部分命中位于条件分支                       |
| 投射物承载部分或全部伤害 | 安塔尔、伊冯、卡缪                                           | 只读取主技能直接伤害会漏算；安塔尔主技能没有直接伤害 |
| 显式分黑板倍率           | 艾尔黛拉                                                     | `atk_scale1 + atk_scale2` 分别保存 20% 和 80% 部分   |

各角色的处决可打断时刻约为第 42 至 75 帧，命中时刻和动画总长也不同，不能共享固定
`duration` 和 `hit offset`。多段动作还会把终结技能量获取分摊到不同命中，生成器必须顺序
解析完整动作树和投射物回调，不能仅按展示倍率生成单个伤害步骤。

## 下落攻击

### 共同结构

下落攻击在原始技能系统中至少分为两个阶段：

1. `plunging_attack_start` 进入空中下落状态，本身通常不造成伤害；
2. `plunging_attack_end` 在落地时执行伤害和资源动作。

部分干员还有 `plunging_attack_projhit` 或投射物回调。对 Endaxis 用户而言，这些阶段共同组成
一个可拖动的“下落攻击”，不应暴露为多个技能块。

落地伤害通常具有：

- `NormalAttack | PlungingAttack` 标签；
- 标准攻击倍率计算，而不是 `BreakingAttackCalculation`；
- 等级 1 到 12 的展示倍率 `80/88/96/104/112/120/128/136/144/154/166/180%`；
- 技能等级跟随普通攻击等级。

### 差异与例外

- 伤害元素随干员变化，并不统一为物理伤害；
- 落地段的可衔接帧约为 12 至 25 帧，完整动画数据约为 85 至 228 帧；
- 汤汤的实际黑板倍率为展示倍率的四分之一，需继续追踪其命中次数或目标选择语义；
- 雪绒、卡切尔、终末仪式的直接伤害动作还带有 `0.5` 拆分倍率；
- 伊冯存在多组受 Buff 条件控制的落地伤害，并带有下落攻击相关潜能冷却逻辑；
- 佩丽卡落地后还发射四个投射物；
- 阿黛拉会继承/创建 Buff；
- 庄方宜包含 Buff 条件、继承和当前技能中断动作。

下落持续时间取决于角色何时落地。当前 Endaxis 不模拟高度、重力和移动状态，因此技能定义
只描述 `plunging_attack_end` 的落地执行段；时间轴实例需要由用户决定落地时刻。不能把原始
`plunging_attack_start` 的 1500 帧上限当成技能块固定时长。

## 对新版模型的约束

1. 两类技能均使用独立 `SkillGroupDefinition`，等级通过 `levelSource` 共享普通攻击等级。
2. 处决的 `dealDamage` 必须标记 `calculation: 'breakingAttack'`。
3. 下落攻击仍使用标准伤害计算，但添加 `plungingAttack` 标签。
4. 处决定义需要 `targetStaggered` 释放条件。
5. 生成器必须遍历条件分支和投射物命中技能，不能把 UI 展示总倍率机械写成单次命中。
6. 下落攻击的空中阶段属于尚未建模的移动状态；当前只生成落地执行段。
