# V2 旧轴与 V3 转换轴的期望总伤对比（2026-09-20）

本次以**同一份公开分享轴在 V2 加载后的期望总伤为 100%**，分别比较 V3 的“保留原时间”和“智能修复”转换结果。百分比 = V3 期望总伤 ÷ V2 期望总伤 × 100%；100% 表示数值相同，低于或高于 100% 表示 V3 计算值较低或较高，**不代表转换已经正确或错误的具体原因**。

## 范围和结果

- 样本：157 份公开分享文件、256 个场景；V2 实际加载并模拟 256 个场景。源文件按 SHA-256 核对，重复文件未重复计数。
- V3 两种转换方式都可模拟：233 个场景；其中 194 个 V2 期望总伤大于 0，可计算百分比。其余 23 个场景涉及 12 份文件的模拟转换缺口，没有填入推测值。
- 39 个可模拟场景的 V2 总伤为 0，百分比没有定义；两种模式各有 19 个 V3 也是 0、20 个 V3 大于 0。另有 2 个 V2=0 的场景落在转换缺口内。

## 统计口径

- V2：使用 `Lieyuan621/main` 的 `13b6905c`，在 V2 实际导入原始分享文件并逐场景模拟；按 V2 伤害分析的口径汇总模拟起始线之后、队伍轨道来源的正数 `DAMAGE_HIT`，伤害取 `getHitDisplayDamage`，最后汇总为整数。本批 256 个场景的该显示值与原始期望值相同。
- V3：使用本分支 `de51d701`。同一来源分别执行 `preserve` 与 `repair` 转换，加载所得项目并模拟到各自的模拟终点；汇总起始帧之后、目标为敌人的 `DamageApplied.data.expectedDamage`。V3 显示时的取整不参与百分比计算。
- 两代运行时的模型、游戏数据和具体命中集合可能不同。这里比较的是各版本实际加载后的期望总伤，不是只检测转换器是否保留原定时，也不是同一伤害引擎的 A/B 测试。
- “转换缺口”表示转换报告有模拟语义问题，故跳过该场景的 V3 总伤；纯显示问题不阻止统计。“V2=0”不使用无穷大或伪造百分比。
- 本次 14 个有显式模拟终点的可模拟场景中，智能修复的终点相对 V2 均后移，后移幅度为 1.9–52.3 秒；保留原时间的终点有 6 个后移超过 0.5 秒，最大后移约 5.5 秒。这些场景的百分比混有统计时长变化。
