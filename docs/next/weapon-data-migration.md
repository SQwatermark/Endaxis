# 游戏数据版本策略

更新于 2026-08-30。Endaxis Next 尚未发布第一个稳定数据版本，当前只保存和使用唯一最新游戏数据目录。

## 当前规则

- 武器、装备、套装、干员、Buff 和能力实体均不保存 r1/r2/r3 等历史运行定义。
- `gameDataRevision` 当前固定为 `endaxis-next-definitions-latest`，只是项目来源与重新导出的诊断标记，
  不对应可选择的历史规则集。
- 打开项目时直接使用最新目录校验全部引用。引用有效则归一 revision 标记并提示重新导出；引用失效则
  在原位置报错，不猜测替代身份，也不恢复历史定义。
- 武器资源 ID 到 UI/i18n slug 的映射属于当前展示目录，不是旧武器快照。
- 不提供逐 revision 迁移器、迁移预览、旧定义备份包或浏览器迁移备份 UI。

项目文件本身仍由常规导入流程解析；这里取消的是游戏数据内容迁移，不是项目文档 schema 的必要升级。

## 何时重新评估

首个稳定版本发布后，只有真实用户项目出现无法按最新目录解释的兼容需求，才设计所需的最小迁移。
在此之前，生成结果变化由来源审计、`--check`、聚焦模拟和类型检查约束，不通过复制整个旧数据目录处理。
