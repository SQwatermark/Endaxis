# 项目模板与编辑器

编辑器修改用户文档，编译器和模拟器解释它。允许编辑不等于保证输入可模拟；
引用失配应在使用位置报告，不暗中删除技能、改帧或替换定义。

## 模板、实例和单次覆盖

内置定义只读。项目级干员、武器、装备和套装模板使用同一套公共类型，完整保存于项目定义库。
从已有模板派生是一次完整复制，`origin` 仅记录来源，不参与运行时继承或隐式合并。
轨道保存模板引用和自己的养成实例；多个轨道引用同一项目模板时，共享定义但不共享运行状态。

记录key、模板ID与定义身份需要一致；展示资源身份单独保存。
复制或导入出现冲突时要明确分配身份并重写相关引用，不能覆盖另一份定义。
删除被引用内容应处理引用保护，不能留下隐蔽失配。
当前字段以 [项目格式](../../src/core/project/schema.ts) 为准。

模板编辑修改整个定义，技能块编辑只修改该次释放的完整覆盖。
两处可以复用表单，但不能产生隐藏的双向绑定。详情见 [技能](skills.md) 和 [装备](equipment.md)。

## 草稿、页面和历史

同一根定义的编辑共享草稿、历史和保存范围。技能、Buff、能力实体是平级定义对象，
从引用跳转应切换详情，而不是复制一份可写对象或把引用关系画成所有权。
概览、对象列表和定义详情分别承担基础配置、查找管理、结构编辑的任务。
返回与面包屑表达真实归属；浏览和选择不创建撤销事务。

图显示流程、条件和对象关系，Inspector编辑所选对象的值。
图编辑器的调用方提供与文档类型匹配的投影函数，包装字段通过读写适配器转换，
不能把界面包装层写进用户文档。

编辑提交由 [场景会话](../../src/application/editor/scenarioEditorSession.ts) 等应用层入口组织。
一次完成的操作对应一次撤销，取消、失焦和异步失败不能留下半次修改。
整组技能放置读取定义配置与输入路由，不在界面按干员名称写专用链。

## 输入区域与手势

[快捷键路由](../../src/ui/keyboard/keyboardShortcutRouter.ts) 管理逻辑区域与输入归属。
弹窗阻隔背景命令，子区域关闭后恢复父区域；Teleport改变DOM位置，不改变逻辑归属。
文本输入优先保留原生编辑行为。按住键的状态与一次性命令分开处理，失焦或区域改变时清除按住状态。

[手势会话](../../src/ui/interaction/interactionSession.ts) 区分所有者和会话身份。
只有当前持有者能够更新、提交或取消；旧清理回调不能结束后来启动的手势。
指针拖动、原生拖放和点击后跟随放置有不同结束策略，不能因外观相似就混用事件语义。
无效悬停不自动提交，Escape、pointercancel、失焦和卸载都需要明确取消路径。

图层只控制显示和命中，不能替代目标合法性或输入归属。
拖动预览不抢指针；工具栏、快捷键与菜单调用同一个编辑命令。

## 语言、主题与性能

界面文本与游戏内容文本分别组织，按需要加载。语言切换在所需资源准备完成后生效，
较慢的旧请求不能覆盖新的选择；加载失败不冒充缺失翻译。
自定义名称属于用户内容，固定界面文案才进入界面翻译。

组件使用语义主题变量，主题不改变战斗规则。用户保存的自定义颜色属于项目展示属性，
不能与界面主题混为一谈。语言和主题切换不创建编辑历史或重跑战斗。

模拟服务使用同一套正式模拟器，并根据最近三次完整模拟的耗时选择拖动时的执行位置。
最慢一次不超过33毫秒时，整次拖动在主线程同步计算，让技能块和投影在同一次绘制前更新；
没有耗时样本或最慢一次超过33毫秒时，整次拖动交给Worker。执行位置只在拖动开始时选择，
拖动中不切换，也不靠平移旧投影伪造实时结果。普通编辑仍交给Worker。

状态只属于该次模拟。缓存覆盖输入和规则版本、保持容量上限，取消或失败结果不进入有效缓存。
已经开始的计算允许完成，尚未开始的请求合并为最新一次；旧结果不能覆盖更新的编辑。
实际性能和交互验收方法见 [验证指南](../development/validation.md)。
