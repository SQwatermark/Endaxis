## 一套归属模型，三个职责

### 1. 交互区域和浮层登记

每个编辑器实例、菜单、弹窗有独立身份、逻辑父区域、活动状态和根元素。
Teleport 改变 DOM 位置，不改变逻辑父区域。名称只用于调试，不能充当实例唯一键。
最后活动编辑区域、当前文本焦点、最上层模态区域分别保存，不混成一个 active 布尔值。

模态打开建立屏障：背景区域不能执行命令或启动手势。嵌套菜单只处理其所属弹窗内
的输入，关闭后恢复父区域，不因注册时序或 CSS 数字意外回到时间轴。
Element Plus 浮层需要适配其打开/关闭生命周期；迁移期间保留现有保护，不能先删后补。

### 2. 手势会话

会话包含 token、owner、操作类型、输入方式、pointerId（适用时）、预览与结束回调。
同一工作台一次只能有一个互斥编辑手势。开始新手势必须申请，不能覆盖现有状态。
会话持有者才能更新、提交、取消；过期清理回调不能结束后来开始的操作。

- 指针手势由稳定根元素捕获，并过滤 pointerId。其他控件不能在经过时接管。
- 原生 HTML DnD 通过独立适配器接入同一会话，不假装它拥有 PointerEvent 捕获语义。
- 点击跟随放置有不同的结束策略，但仍属于会话，不能被拖动排序/分隔线隐式替换。
- 悬停无效区域只更新预览/目标状态，不结束会话。实际释放按该工具明确的提交/取消
  规则处理；不把所有工具强行统一成一种“无效放下”行为。
- Escape、失焦、pointercancel、源组件卸载等有明确且幂等的取消路径；撤销不留下
  半次拖动。一个提交形成一次所属文档的撤销事务。
- 自动滚动是当前会话的服务，不另行抢占。拖动预览不参与指针命中。
- 可接受目标按载荷类型与区域角色解析，不能仅由 event.target.closest 和覆盖控件
  恰好返回的元素决定。显示层级不能替代目标合法性判断。

### 3. 命令与快捷键

按键、右键菜单、工具栏调用同一应用命令；命令的 owner 决定选择对象、剪贴板语义
与撤销历史。UI 路由器不负责模拟，也不因校验不通过拒绝编辑。

路由先确定最上层可交互区域，再在该区域内确定活动手势/菜单/编辑器：

1. IME 组合输入和已处理事件不再分发编辑命令。
2. 活动手势先接收其取消/修饰键；其他编辑命令在会话期间按明确白名单处理。
3. 菜单或模态屏障阻止命令落到背景，即使自己没处理该键。
4. 文本控件保留原生复制、粘贴、撤销、光标操作；Escape 等由所属浮层决定。
5. 非文本区域的复制、粘贴、删除、撤销只交给其所属编辑文档，不向另一编辑器兜底。

不能仅用“图层 priority 更大”确定键盘拥有者。现有 priority 路由作为迁移设施保留，
最终由逻辑区域/浮层栈限定候选集。也不能用全局 stopImmediatePropagation 吞掉全部
事件来掩盖尚未迁入路由的监听器。

## 显示与命中分层

| 边界         | 内容                                  | 规则                                                |
| ------------ | ------------------------------------- | --------------------------------------------------- |
| 画布局部     | 网格、持续段、技能、图标、hit、选择框 | 保留有意义的局部顺序；受画布裁剪                    |
| 固定区域     | 标尺、SCALE、干员列、监控标签         | 遮挡滚动画布，不被技能选择/预览穿透                 |
| 局部编辑控件 | 折叠按钮、尺寸手柄                    | 明确同层冲突优先级；不能夺取已开始的会话            |
| 页面浮层     | tooltip、菜单、弹窗及其子浮层         | 统一层级出口和逻辑父子归属；子菜单不能逃出模态屏障  |
| 拖动预览     | 跟随技能、辅助提示                    | pointer-events:none，不改变有效落点，不压过模态屏障 |

后续提取语义化 CSS 层级变量，但先核对 stacking context、isolation、overflow、
Teleport 边界；禁止仅全局替换 z-index 数字。鼠标命中、键盘归属、视觉层级是三个
不同问题，共享区域身份而不相互冒充。

## 迁移顺序与验收门槛

1. **入口清点与路由收紧（本轮）**：本文；同名作用域实例独立释放；已消费/IME 按键
   不分发；时间轴动作菜单 Escape 接入现有路由。尚非全局交互问题解决。
2. **首条完整手势链**：复现三种技能放置，接入会话；同时接入轨道排序、主面板尺寸
   调整这些竞争入口。不能只新增管理器而旧入口仍能无条件写共享状态。
3. **其余手势与键盘区域**：框选、平移、连接线、标记、各尺寸手柄，以及导图/属性
   编辑器/菜单的命令归属。撤销历史按文档分开，取消不穿透。
4. **浮层与层级统一**：接入模态父子栈和 Element Plus 生命周期，再替换枚举弹窗/
   DOM 猜测式保护；同时迁移语义层级，不改旧版合理的视觉效果。
5. **组合验收后删旧路径**：真实深色完整页面验证，而非仅源码字符串断言。

最低回归矩阵：三种技能放置经过 drag-handle/折叠按钮/分隔线/标尺/侧栏；同轨与
跨轨落点；自动滚动；Escape/失焦/源卸载；第二指针；旧会话迟到回调；菜单关闭
同一个 Escape 不再取消底层操作；弹窗内输入框与导图 Ctrl+C/V/Z；双编辑器实例；
一个操作一次撤销；无效模拟仍能编辑；滚动/折叠/缩放后固定区遮挡。

测试分三层记录：纯路由/会话状态机测试、组件接线测试、浏览器真实事件验证。
第一层通过不能宣称 drag-handle 实际缺陷或视觉层级已经验收。
