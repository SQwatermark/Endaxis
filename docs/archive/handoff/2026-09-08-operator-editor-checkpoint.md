## 实际复查中修复的问题

- 技能调度节点添加步骤漏了 `.sequence` 路径，导致菜单关闭但没有新增。已修复，并从实际节点命令起点测试，避免手工填对路径掩盖缺陷。
- 通用动作图内联 Buff 漏传字段绑定；技能/动作图撤销恢复漏识别内联 Buff，导致不能回到完整字段位置。已补齐。
- 技能总览入口错误地显示并返回技能库组织。现区分进入来源，并保存到视图历史/引用返回快照。
- 属性修正主/副/全部属性对象不能用普通字符串输入表示；已提供联合类型选择。
- 失衡条件的 DamageTag 误用 GameplayTag 编辑控件；已区分两个协议。
- 表现最后一个字段清空不应删除当前对象；相同类型选择不应重置已有值。
- Buff 提供标签的短名称误填成整段帮助说明；中英俄短名称已修正，长说明留在帮助中。
- 提交前补跑发现佩丽卡潜能测试残留旧 key 断言，已改为固定档位的单级定义断言，行为断言保留。
