# 本地环境

Git只保存通用说明。实际机器信息保存在被忽略的文件中：

| 文件                                        | 内容                                           |
| ------------------------------------------- | ---------------------------------------------- |
| `.local/handoff/environment.md`             | 仓库路径、工作树、游戏安装、服务和最近核验时间 |
| `.local/handoff/process-memory-20260911.md` | 转储、地址索引、符号文件的准确位置和读取示例   |

这些文件不会随clone或pull同步。缺少时先检查本机文件系统，不套用另一台机器的记录。
新环境可按 [模板](environment-template.md)建立记录。

## 读取现有转储

已有可读进程导出约11.7 GiB，二进制数据必须与同名JSON地址索引配对保存。
采集不是在同一瞬间完成的，也有不可读区域；它不是Windows minidump或事件历史。
先检查JSON完整标记和数据长度。combat-spec的 `tools/process_memory_reader.py`
只加载索引，然后按地址读取，每次最多1 MiB，不把整个二进制放进内存。

分析现有文件不需要启动游戏。只有缺少必要的状态变化时才重新采集。
零字节的失败 `.dmp` 不能作为证据。转储、游戏文件和私有进程数据不上传Git。
