# 验证与真实轴对照

根据改动选择能暴露问题的检查，不以测试数量代替覆盖结论。
类型、单位测试、真实数据、浏览器交互和游戏证据分别说明了不同事情。

## 按问题选择检查

| 改动           | 重点检查                                           |
| -------------- | -------------------------------------------------- |
| 公共类型或编译 | 可选字段、联合关系、等级解析、未知字段与引用错误   |
| 公式           | 边界、乘区、float32顺序与同版本证据                |
| 事件与生命周期 | 顺序、同一载荷、嵌套来源、重入、失败清理和独立存活 |
| 数据生成       | 来源版本、完整候选、引用闭包、正式生成差异         |
| 编辑与存档     | 连续修改、取消、撤销重做、重开项目和稳定身份       |
| 界面           | 真实入口、模态隔离、拖放、窄屏、深浅主题与语言     |
| 文档           | 链接、代码入口、过时要求、重复正文与证据分级       |

命令见 [开发指南](README.md)；生成命令只维护在转换器README。
检查串行执行，测试限制worker数量，不同时加载大转储或启动多份类型检查。

## 真实轴保持原输入

保存原始样本、来源标识、构筑、主控切换、时间位置和版本。转换过程需要记录不能对应的内容，
不能为了减少告警或缩小差异而改变原轴。用于诊断的修改另存为变体，并说明改了什么。

按每次命中的时间、来源、数值、资源和状态比较。区分旧版近似、新版缺陷、证据缺失以及随机差异，
每项结论都应有来源和覆盖边界。公开样本的应用测试入口是
[publicShareRegression.test.ts](../../src/application/simulation/integration/publicShareRegression.test.ts)。
私有样本及本机临时产物的位置留在 `.local/`。

## 性能与界面

固定短轴、长轴和多状态样本，在同一机器与构建模式下比较首次运行、重复编辑和连续操作。
记录耗时、主线程响应和内存趋势。没有测量就不承诺倍数，也不因单个微基准改善声称整页更快。
缓存应有上限，关闭项目与取消任务后检查资源释放。

浏览器验收从正式页面进入，覆盖保存、关闭、重开和取消。
代码接线通过不等于所有弹窗都已点验；截图只证明对应页面状态，不能替代拖放或键盘交互。

## 记录结果

记录实际命令、退出结果、版本、样本与未覆盖部分。批次重叠不能相加成为全量数量。
环境错误与断言失败分别写清；尚未解决的环境失败仍不能算通过。
当前交接只保留最新有效结论，详细过程放历史记录，不反复抄进架构说明。
