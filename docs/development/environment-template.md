# 本地环境文档边界与模板

这份文件只规定如何记录环境，不描述任何一台真实机器。需要保存本机信息时，将下方模板复制到
`.local/handoff/environment.md`；`.local/`已被Git忽略。

## 应当进入 Git 的内容

- 项目职责、公共架构、稳定协议和设计决策；
- 带游戏版本、文件哈希或提交号的可复核证据结论；
- 使用占位符或仓库相对路径的通用命令；
- 当前主线、已完成项、未完成项及其证据边界。

历史研究记录可以说明证据当时来自哪类机器或工具，但机器名称不能被解释成当前环境状态。

## 只应保存在 `.local/` 的内容

- 本机绝对路径和完整工作树清单；
- 当前分支、HEAD、dirty状态和stash清单；
- IP、SSH用户、端口、转发命令和服务进程；
- 游戏安装路径、临时导出、未入库证据和大型缓存位置；
- 只适用于某一台机器的新会话提示词。

这些信息易变、不可由另一台机器复核，并可能混淆同步后的新会话。
