# 文档维护与本次清理

新文档只保留一套当前说明。架构解释系统职责，开发指南解释操作方法，交接记录当前工作，
研究保存游戏证据，历史区保留已经退出当前维护的设计与过程。

## 本次处理

- 用数据、技能、运行时、事件、伤害、装备、时间和编辑器八个主题替代零散架构说明。
- 删除24个已被替代的教程、索引或跳转页，取消 `docs/next` 并行入口。
- 将其余旧架构方案、专题和带日期交接移入 `docs/archive`，逐页注明历史性质并建立完整索引。
- 研究材料分为战斗、干员、装备、生成和显示，保留来源与JSON证据，逐篇提示版本与覆盖边界。
- 环境模板移入开发指南，准确本机信息继续保存在 `.local/`。
- 修正旧的逻辑帧映射、技能结束边界、装备接入状态和已取消的门禁要求；历史正文只供追溯。
- 更新搬迁引用和审计输出目录，避免工具再次生成到废弃位置。

归档不是宣称旧稿的所有游戏结论都正确，也不是把历史缺口全部判定为已解决。
保留完整原稿是为了让独有证据、版本、样本和推导仍能追溯；当前文档不再依赖它们解释基本架构。

## 以后怎样写

先确认已有主题能否容纳内容。直接更新对应页，不新建另一份“最新总览”或在顶部累积进展日志。
架构中的代码入口用链接引用，不复制大型接口、枚举和命令表。
功能完成度只写在交接；具体样本与覆盖结果留在对应验证或研究记录中。

删除或移动文件时同时检查Markdown链接、代码注释、测试引用和工具默认输出路径。
机器可读审计文件不手工改内容；原始数据、缓存和大转储不纳入共享文档。
